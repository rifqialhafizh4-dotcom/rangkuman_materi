# Rangkuman Materi Pelatihan

Selamat datang di repository tugas kedua saya! Repository ini berisi catatan dan rangkuman materi pelatihan mengenai Git dan GitHub.

## Isi Repository
- `file.txt`: File teks yang memuat rangkuman materi pelatihan secara lengkap.

## Topik Pembahasan
Rangkuman di dalam repository ini mencakup beberapa materi pokok, antara lain:
1. **Version Control System (VCS) & Git**: Penjelasan konsep dasar VCS (Lokal, Terpusat, Terdistribusi) beserta kegunaan utama Git untuk pelacakan dan kolaborasi.
2. **Dasar-Dasar Git**: Panduan perintah dasar di terminal seperti pengaturan konfigurasi, `git init`, penambahan file ke *staging area* (`git add`), pembuatan *commit*, hingga melihat riwayat perubahan (`git log`).
3. **Penggunaan Remote & GitHub**: Langkah-langkah mengkloning repository, menambahkan *remote*, serta panduan menghubungkan repository lokal ke platform GitHub hingga proses *push*.
